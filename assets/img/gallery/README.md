# 시공 갤러리 이미지 (21개 키워드 슬롯)

이 폴더의 **webp 파일**은 각 키워드별 시공 사진입니다. 메인 페이지와 모든 지역
페이지의 "시공 갤러리" 영역에 자동으로 노출됩니다. (800×600, 4:3, 약 50KB)

## 사진 교체 방법
1. 새 사진을 4:3 비율(예: 1200×900)로 준비합니다.
2. 아래 파일명과 동일한 이름의 **webp**로 저장해 덮어씁니다.
   - jpg/png만 있는 경우 파일을 폴더에 넣고 알려주시면 webp(~50KB)로 변환·교체해 드립니다.
3. 지역 페이지는 21장 중 6~8장이 지역별로 회전 노출되고, 메인 페이지에는 21장 전체가 노출됩니다.
